DRL+TL dual-pronged approach! A new study on intelligent interference mitigation technology for wireless networks
Abstract: Interference attacks are one of the core security issues in wireless networks. They cause network congestion by blocking channels and interfering with user signals, significantly reducing network throughput. Existing research has proposed using deep reinforcement learning (DRL) models to address interference attacks, which possess the capability to predict the decisions of interference machines and recognize patterns. However, training a DRL model from scratch is often time-consuming. This paper first proposes a recurrent neural network architecture to minimize the number of training parameters for the DRL model; furthermore, it introduces transfer learning (TL) methods to enable the DRL intelligence to quickly learn in dynamic wireless networks, thereby effectively combating interference attacks. To adapt the proposed transfer learning method to different network environments, this paper designs a novel method based on an ensemble feature extractor that quantitatively measures the differences between source and target domains and selects the optimal configuration for the transfer learning model based on the measurement results. Experimental results show that the proposed transfer learning method can effectively shorten the training time for the DRL model and outperform other existing transfer learning methods.
Introduction: With the continuous development of wireless networks, the attack techniques against wireless networks have also evolved, becoming increasingly complex. Research has achieved efficient and intelligent interference machine designs, thus urgently requiring flexible and effective methods to counter interference attacks.
Research has confirmed that predicting the behavior of jammers using machine learning is one of the effective means against jamming attacks. However, in wireless networks with jammers, the unpredictable behavior of the jammers leads to dynamic changes in the network environment, making it difficult to collect data and construct a dataset suitable for machine learning algorithms. This makes most machine learning methods, such as supervised learning and unsupervised learning, challenging to implement—they require pre-existing datasets to be prepared before learning begins. Deep reinforcement learning, as a branch of machine learning, does not require prior environmental information and completes its learning through iteration, which highly aligns with the dynamic characteristics of wireless networks. It also possesses good generalization capabilities, capable of solving the anti-jamming challenges traditional network protocols struggle with. Especially when facing intelligent jamming attacks, if an appropriate anti-jamming system is lacking, the throughput of the target network will suffer severe losses. In contrast, DRL models can predict complex jamming patterns, making them an ideal choice for wireless network anti-jamming systems.
However, the training process of DRL models requires substantial time and computational resources. Moreover, when the network environment changes (e.g., interference patterns change), the DRL model needs to be retrained to adapt to the new environment. To address this, this paper proposes a transfer learning approach to accelerate the training process of DRL models in response to changes in network environments. Transfer learning can significantly reduce the training time for DRL models in the target domain, enabling them to make faster predictions about interference patterns, thereby preventing a decline in network throughput. The adaptive algorithm of the transfer learning model must adjust its configuration based on the environmental differences between the source and target domains. Therefore, this paper designs an approach that utilizes an ensemble feature extractor (IFE) combined with relative entropy to measure the differences between the source and target domains. This method enables the selection of optimal configurations for the transfer learning models in the target domain, achieving efficient use of time and computational resources.

Method Overview: The intelligent interference mitigation method proposed in this paper centers around deep reinforcement learning, integrating transfer learning and feature relevance explanation methods to achieve efficient interference resistance. A corresponding wireless network system model has been designed, which is divided into three core parts as follows:
1. The researched wireless network consists of multiple wireless access points (APs), each providing services to IoT devices and mobile sensor robots within a specific area. The network employs a frequency hopping communication system, with each AP connected to the backhaul network via N available channels. Time is designed using slotted time division, where each AP corresponds to one active user, and the user's signal transmission requires T slots.
2. Access points are equipped with DRL agents that decide on the communication channel based on network observation results. If an interference machine interferes with the same channel during the signal transmission slot, transmission fails; otherwise, it succeeds. The network throughput is defined as the ratio of successful transmission attempts to total transmission attempts, with the core goal being to maximize network throughput.
Research Considers Two Typical Interference Machines: Scanning Frequency Interference Machine (Implementing interference in all frequency channels in a fixed order cyclic scanning); Random Interference Machine (Randomly interfering some frequency channels according to a specific probability distribution). The network environment of the first access point that trains the deep reinforcement learning model is defined as the source domain, while the network environments of the other access points are defined as the target domain. This accelerates the training of the deep reinforcement learning model by knowledge transfer from the source domain to the target domain.
II. Deep Reinforcement Learning Model
Observation and State Definition: Channel states after signal transmission are taken as observation values, which include idle, user successfully occupied, only interfered, and interfered transmission types; recent K observations are concatenated into the input state of the DRL model, which can contain more information about the behavior of interference machines, and K can be flexibly selected based on the storage capacity of the access point.
2.
Reward Function: The agent receives a positive reward of 1 when transmission is successful and a penalty of -0.1 when it fails, with the absolute value of the penalty being less than the reward, adapting to the characteristics of the DRL agent's exploration process where more errors are made.

Network Architecture: Considering the input as time-series data, an LSTM network is used as the core recurrent neural network architecture, introducing Dropout layers to reduce computational complexity and avoid overfitting; the specific architecture is an 8-unit LSTM layer (10% Dropout) + 64-unit ReLU layer (10% Dropout) + 32-unit ReLU layer (10% Dropout) + 16-unit ReLU layer + a Softmax layer matching the number of actions.
III. Transfer Learning Method Based on Integrated Feature Extractor (IFE)
The core advantage of transfer learning lies in not requiring all access points to train the DRL model from scratch, but only the source domain access points to complete full model training, then transferring the knowledge to the target domain access points, which can also adapt to changes in interference machine behaviors, quickly learning new anti-interference strategies.
Integrated feature extractor for transfer learning, with core strategies of layer freezing and partial retraining: After the target domain's DRL model receives parameters from the source domain, it freezes the first few layers as a feature extractor. Only the last few layers are trained to adapt to the interference patterns in the target domain. The number of frozen layers is determined based on the differences in interference behavior between the source and target domains. This method significantly reduces the number of trainable parameters in the target domain, achieving faster convergence speed. This is because the neural network's first few layers store general features of the input data, while the last few layers focus on specific learning tasks. Freezing the first few layers does not lose essential features, while also reducing training complexity.
IV. Feature Relevance Explanation (FRE) method is used to quantitatively measure the differences in interference behavior between source and target domains. It designs a feature relevance explanation method based on explainable artificial intelligence (XAI), which extracts the importance of channel features to indirectly reflect the behavior of interference machines. The core consists of three steps:
1  
Random Forest Tree Generation: Input the channel state observation values and the Q-values generated by the DRL model into the random forest. The random forest consists of multiple decision trees, where decision trees split based on the Gini index, randomly sampling features to complete node splits until there are no new split conditions or the Gini index falls below a threshold.
2  
Feature Importance Calculation: Based on the decision tree node split results, calculate the importance of each channel feature. Then, take the average of all decision tree results in the random forest to obtain a normalized feature importance distribution.
3  
Relative entropy calculation: Extract the feature importance distributions and from both source and target domains, calculate the KL divergence (relative entropy) as a quantitative measure of domain differences. The higher the relative entropy value, the greater the difference in interference behavior between the source and target domains.
Determine the number of trainable layers in the target domain DRL model based on the measurement results of relative entropy: the smaller the domain difference, the fewer the trainable layers. The larger the domain discrepancy, the more layers that can be trained to achieve adaptive configuration for transfer learning models.
Conclusion This paper investigates a time-efficient wireless network anti-interference method for scenarios where jammers attempt to interfere with multiple communication areas. It compares and verifies the advantages of Recurrent Neural Networks (RNN) over Convolutional Neural Networks (CNN) in the application of DRL models for wireless network anti-interference - RNN possesses fewer training parameters, exhibits faster convergence speed, and achieves superior throughput.
To address the issue of excessive training time for DRL models when trained from scratch for various regions, this paper proposes a transfer learning method based on an ensemble feature extractor. This method can flexibly adapt to differences in interference behavior between the target and source domains, achieving acceleration in the training process. Additionally, a random forest-based feature relevance explanation method has been designed to quantitatively measure the differences between the source and target domains, providing a basis for the configuration of transfer learning models. Experimental results show that the proposed transfer learning method can effectively shorten the training time for DRL models, and outperforms existing methods such as classifier transfer learning and weight initialization transfer learning, as well as traditional DRL methods trained from scratch across all test scenarios.
The future research directions of this paper mainly include two aspects: one is to study the interference scenarios of multi-active users communicating through available channels, and expand the scope of methods; Secondly, explore the precise correspondence between relative entropy values and the optimal number of trainable layers in transfer learning models to further enhance the model's adaptability.
